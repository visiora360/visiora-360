# Visiora 360

Sitio web oficial de Visiora 360 y base para Digital Open House.

## Archivos principales

- `index.html` — página corporativa
- `styles.css` — diseño y responsive
- `script.js` — menú móvil y animaciones
- `assets/` — logo e imágenes de servicios
- `propiedades/ajusco/index.html` — primera ruta de Digital Open House
